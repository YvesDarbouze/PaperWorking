# Profile Settings

Manage personal account details, name representations, and password credentials.

## Settings Areas

- **Profile Picture & Display Name**: Modify user avatars displayed in team directories.
- **Security & MFA**: Secure accounts using MFA verifications.
- **Linked Accounts**: Verify email credentials.
