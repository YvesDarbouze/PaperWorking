# Brand Interview — PaperWorking Redesign

Reference site: https://antigravity.google/
Date: 2026-06-05

---

## 1. PRODUCT IDENTITY
PaperWorking is a real estate investment operating system (SaaS) that helps serious real estate investors track deals, manage rehab budgets, organize documents, and close faster.

## 2. AUDIENCE PERSONA
Serious real estate investors (ages 28–60) managing single-family or multi-family properties. They are technically sophisticated, data-driven, and highly ambitious but time-poor.

## 3. BRAND FEELING
Minimal, precise, premium.

## 4. COLOR PALETTE
Google Antigravity's high-contrast grayscale palette:
- Light background: `#FFFFFF` (Surface Container: `#F8F9FC`)
- Dark background: `#121317` (Surface Container: `#18191D`)
- Accent color: `#3279F9` (Antigravity Blue)
- Body Text: `#121317` (light mode) / `#FFFFFF` (dark mode)
- Variant/Muted Text: `#45474D`
- Borders: `rgba(33, 34, 38, 0.12)` (light) / `rgba(230, 234, 240, 0.12)` (dark)

## 5. PAGE SECTIONS
1. Landing Header / Nav
2. Hero (typed text style)
3. Dashboard Preview Section
4. Platform Overview (REIL Phases: Sourcing, Acquisition, Rehab, Exit)
5. Investor Profiles / Use Cases Section (Flippers, Wholesalers, Landlords, Syndicators)
6. Pricing Section
7. FAQ Section
8. Final CTA / trial sign-up
9. Footer

## 6. PRIMARY HEADLINE
Headline: "Experience liftoff with the next-gen real estate platform."
Subheadline: "Track deals, manage rehab budgets, and close faster. PaperWorking is the operating system for serious real estate investors."

## 7. PRIMARY CTA
Action: Start 14-day free trial.
Button label: "Get started for free"

## 8. KEY DIFFERENTIATOR
An institutional-grade, deterministic tool that organizes real estate lifecycle tracking (sourcing, pro forma, construction, and exits) with a pure read-only metrics engine and a professional data room.

## 9. ANIMATION INTENSITY
Level: 3 (Moderate - scroll reveals, typography fade-in/up, custom cursor for preview interactions, and smooth hover state transitions).

## 10. TECH STACK
Next.js (React) + Tailwind CSS + Framer Motion (matching the light/dark design system variables).

## 11. CONTENT ASSETS
Logo: Logo wordmark + emblem (Plus Jakarta Sans)
Photography: High-fidelity dashboard screenshots and moody, minimalist real estate structural photography.
Placeholder aesthetic: Bright minimal and abstract geometric.
