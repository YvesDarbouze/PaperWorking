# Deal Analyzer & Compare Board

The Deal Analyzer displays selected properties side-by-side to determine which acquisition deal generates the highest returns.

## How it Works

1. On any project under underwriting or sourcing, click **Add to Deal Compare**.
2. Navigate to **Deal Analyzer** to view the metrics comparison table.
3. Contrast core performance metrics, loan structures, and leverage details.
